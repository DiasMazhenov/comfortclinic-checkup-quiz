# Comfort Clinic · Check-up Quiz

Интерактивный квиз подбора программ обследования для [Comfort Clinic](https://comfortclinic.kz/checkup). Проект встроен в **Tilda T123** и использует существующий каталог из 16 чекапов, расположенный ниже на той же странице. Код написан на чистых HTML, CSS и JavaScript: без npm-зависимостей, сборщика, сервера, API и передачи ответов на сторонние ресурсы.

> **Статус:** исходный код размещён в этом репозитории. Наличие кода на GitHub **не означает**, что соответствующая версия уже записана в Tilda или опубликована. Состояние редактора и публичной страницы проверяется отдельно.

## Быстрый старт

1. Открой страницу «Чекапы» в Tilda. Её Page ID: **253194603** (project ID **19996296**), адрес в настройках — **/checkup**.
2. Найди существующий блок **T123**, Record ID **5520789203**. Он стоит **перед блоком вкладок**.
3. Скопируй **полное содержимое** [tilda/comfortclinic_quiz_T123.html](tilda/comfortclinic_quiz_T123.html) в поле HTML этого блока. Файл уже включает разметку, стили, скрипт и встроенную копию данных 16 программ. Отдельно подключать JSON не нужно.
4. Сохрани блок и открой предварительный просмотр, проверь клавиатуру, мобильную ширину, работу вкладок и переход к записи.
5. После проверки опубликуй страницу средствами Tilda. Публикация **не выполняется** при обновлении GitHub.

Не вставляй квиз в общий Header/Footer: иначе он появится на других страницах. Не добавляй второй ME602A с теми же ID программ.

## Пользовательский сценарий

| Шаг | Что делает пользователь | Правило |
| --- | --- | --- |
| 1. Пол | Выбирает женский или мужской | Обязательный одиночный выбор |
| 2. Возраст | Указывает полных лет от 0 до 100 | Обязательное целое число, диапазон проверяется |
| 3. Направление | Выбирает один профиль | Общий профиль, ЖКТ, щитовидная железа, лишний вес, а также гинекология или урология для взрослых с учётом пола |
| 4. Уточнение | Может отметить несколько тем | Для гинекологии: подготовка к беременности, сбитый цикл, менопауза, общий гинекологический. Для остальных: состав, стоимость, подготовка к приёму. Общий профиль пропускает шаг |
| 5. Результаты | Сравнивает до трёх программ | Название, цена, зачёркнутая цена, выгода, сокращённый состав и действия |

Возрастные группы для отображения: **0–6**, **7–17**, **18–34**, **35+**; при отборе программ используется **точный возраст** и включённые границы ageMin/ageMax. Некоторые каталожные возрастные метки пересекают границу 18 лет, поэтому ориентируйся на данные конкретной программы.

## Алгоритм результата

1. Из 16 программ выбираются только те, где возраст в диапазоне **ageMin ≤ age ≤ ageMax** и пол — выбранный либо "any".
2. Для выбранного направления отбираются программы с соответствующим значением **topic**.
3. Для категории **general** сразу выводятся до трёх программ общего профиля в установленном порядке (детский или взрослый).
4. Если **по выбранному направлению нет ни одного совпадения**, показываются **общие чекапы** для того же возраста/пола. В результатах явно написано, что это альтернативы из общего профиля.
5. Если даже общий профиль пуст, остаётся ручной переход в существующий каталог.
6. Итог ограничен **трёмя** карточками.

Категория **ЖКТ** пока не имеет отдельной программы в текущем каталоге, поэтому переходит на общий профиль. Для детей, которые выбрали направление со взрослой программой, действует та же логика резервного подбора.

**Важно о семантике:** подбор — это фильтрация опубликованного каталога по метаданным (возраст/пол/категория). Выбор уточнения сохраняется в резюме, но **не меняет ранжирование** конкретных программ. Нельзя интерпретировать результат как медицинский диагноз или автоматическое назначение обследований.

## Кнопки и интеграция с Tilda

- **Посмотреть программу:** переключает вкладку штатного блока **ME602A / t1281**, использует хеш вида **#!/tab/5299319803-3**, затем ищет соответствующий **#rec<recordId>** и пытается прокрутить страницу к карточке. Не скрывает напрямую существующие Zero Block.
- **Записаться:** ведёт в существующий popup **#zapis**.
- **Выбрать чекап самостоятельно:** отдельная кнопка на экране результатов, ведёт к блоку вкладок **#rec5299319803**; доступна независимо от количества совпадений.
- **Назад / Начать заново:** возвращают к предыдущему шагу / очищают ответы.
- Ответы и название выбранной программы **не передаются автоматически** в заявку. Кнопка открытия popup **не означает отправки** формы.

Порядок вкладок: **1 Женский · 2 Мужской · 3 Общий · 4 Детский**. При изменении нативных вкладок, их Record ID или связей li_blocks необходимо обновить ссылки в квизе.

## Дизайн и адаптивность

Квиз использует отдельные селекторы **#cc-quiz / .ccq***, чтобы минимизировать конфликты со стилями Tilda. Палитра: основной зелёный **#004341**, розовый акцент; шрифты наследуются от сайта. Адаптивность предусмотрена приблизительно на **950 px** и **650 px**, плюс системная настройка уменьшения анимации. Проверка наличия CSS не заменяет визуальный просмотр в браузере.

## Обновление цен и программ

**Источник данных для разработки:** [data/checkups.json](data/checkups.json). Исходный HTML **содержит отдельную встроенную копию** списка программ, так как T123 должен работать сам по себе. Чтобы изменения JSON дошли в HTML:

~~~bash
node scripts/build.mjs
node scripts/verify.mjs
~~~

После этого **заново вставь** обновлённый HTML в T123 и опубликуй страницу. Изменения GitHub или data/checkups.json сами по себе **не синхронизируют** цены с редактором Tilda. Цены, названия и сокращённые составы нужно сравнивать с исходными карточками Zero Block; справочник не является живым API клиники.

Формат записи:

~~~json
{
  "id": 5336877903,
  "title": "Базовый метаболический",
  "tab": 3,
  "topic": "general",
  "price": 66800,
  "oldPrice": 81500,
  "saving": 14700,
  "gender": "any",
  "ageMin": 18,
  "ageMax": 100,
  "services": ["Приёмы эндокринолога", "Развёрнутый анализ крови"]
}
~~~

Числовые ID — **ID существующих блоков Tilda**, а не произвольные ключи. Поле services содержит **краткий анонс**, а не полный медицинский прайс; полный состав хранится в нативной карточке.

## Проверки и ограничения

~~~bash
node scripts/verify.mjs
~~~

Скрипт проверяет корректность данных, уникальность ID, суммы выгоды, соответствие встроенного справочника JSON, отсутствие нежелательных пользовательских заглушек, наличие пяти шагов и основных ссылок. Это **статические проверки**: они не подтверждают работу мобильного dropdown Tilda, скроллинг, popup записи или качество верстки на опубликованном сайте.

Рекомендуемые ручные прогоны: женщина 28 лет / гинекология; мужчина 42 года / урология; ребёнок 8 лет / общий профиль; взрослый / ЖКТ (fallback); ребёнок / щитовидная железа (fallback); граничные значения 0, 6, 7, 17, 18, 35, 100; пустой ввод, назад, сброс, мобильная версия, открытие конкретного Zero Block и общей формы.

## Конфиденциальность и обслуживание

Ответы обрабатываются в браузере и не сохраняются скриптом в localStorage/cookie, не отправляются fetch/XHR. Это не аудит всех сторонних скриптов Tilda, аналитики или расширений браузера. В репозитории нет API-токенов; подключение Tilda MCP и учётные данные не должны храниться в исходниках.

Изменения в этом репозитории **не затрагивают** уже опубликованную страницу до отдельной операции обновления T123 и публикации.
